### 🟦 Microsoft Fabric E-commerce Customer 360

Built an end-to-end Customer 360 data engineering solution using **Microsoft Fabric, Azure Storage, PySpark, Fabric Lakehouse, and Power BI**.

- Built a metadata-driven ingestion pipeline from Azure Storage into Microsoft Fabric
- Implemented **Bronze, Silver, and Gold** Medallion architecture
- Cleaned and transformed customer, order, payment, support, and web datasets with PySpark
- Created consolidated **Customer 360** and customer-summary Gold datasets
- Added validation checks across source, Silver, and Gold tables
- Prepared curated data for semantic modelling and Power BI reporting

**Tech:** Microsoft Fabric • Azure Storage • PySpark • Spark SQL • Power BI • Git/GitHub

### ☁️ FEMA Cloud-Native Data Pipeline

Built a cloud-native data pipeline for FEMA Public Assistance data using **Python, Google Cloud, BigQuery, Cloud Run, Cloud Storage, Cloud Scheduler, and Terraform**.
